**Architecture:** Reuse yt-dlp, ffmpeg, Telegram delivery and cleanup. Lazily reuse one spotDL client, run blocking work off the event loop, and serialize downloads. Spotify metadata identifies matching YouTube audio; X downloads all videos from the linked post directly through yt-dlp.

**Tech stack:** Existing Python bot plus spotDL 4.6; Python 3.11+.

**Spec:** The user's accepted spotDL recommendation and request for fast, efficient implementation in this conversation.
